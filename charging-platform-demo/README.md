# 东软电动汽车充电桩应用管理平台 Demo

这是基于当前项目说明书、需求矩阵、接口函数清单和模块数据流说明整理出的 PM 用户端演示原型。原型采用静态 Web 页面实现，目标是帮助 PM 先讲清“充电用户端部分”的需求闭环；正式开发仍可按文档要求落到 Linux + Qt/C++、SQLite、Socket、多线程等技术栈。

## PM 分工边界

需求矩阵中，高可沁（PM）负责第 1-26 条“充电用户端部分”。第 27 条之后的 PC 服务器端、数据库、大数据可视化大屏、机器学习智能分析分别属于 PRL、PE1、SCML、PE2 分工，PM demo 只保留用户端主展示。

## PM 需求理解

PM 当前主要负责充电用户端，核心任务可以拆为五条主线：

1. 用户入口：手机号免密登录、手机号+密码注册、自动创建默认用户。
2. 找桩体验：区域/地址定位、地址转经纬度、附近电站列表、距离/价格/好评/AI 多维排序、地图站点标记。
3. 电站详情：展示站点价格、距离、空闲桩、详细电桩类型、功率、状态、7 日评价。
4. 订单闭环：充电前未完成订单检查、扫码/输入桩号、预约、开始充电、实时计费、结束结算、延时结束、管理员代结算请求。
5. 我的账户：头像、昵称、钱包余额、充值、用户级别、累计充电时长、退出账号。

## MVP 建议

第一版已经打通登录、站点查询、站点详情、开始充电、进行中订单、结算、余额更新和底部 Tab 框架；当前 demo 还补充了 AI 推荐、预约超时、评价、模拟路线规划和头像信息维护。

## 联调依赖

- PE1 数据库：用户表、电站表、电桩表、订单表、管理员表，以及评价表、预约表、预测结果表。
- PRL 后台：电桩状态同步、用户冻结/解冻、远程重启、紧急断电、管理员代结算。
- PE2 机器学习：未来 1h/6h/24h 负荷、空闲桩数量、高峰预警、故障预测。
- SCML 大屏：读取订单、评价、用户行为、负荷预测和电桩状态做可视化。

## Demo 覆盖

- 用户端：登录/自动注册、定位、地址转经纬度、地图选站、排序、AI 推荐、电站详情、预约、一键导航、开始充电、订单计费、结算、评价、充值、修改昵称、头像维护。
- 协作依赖：需要 PE1 提供用户/电站/电桩/订单/评价/预约数据接口，需要 PE2 提供负荷和空闲桩预测结果，需要 PRL 支持超时/代结算等后台状态同步。

## 已加入的交互功能

- 本地模拟数据库：使用浏览器 localStorage 保存用户、订单、电站、电桩、评价和管理员审批状态，刷新页面后数据仍保留。
- 定位与地址转经纬度：输入地址后生成模拟 lng/lat，并基于当前位置刷新附近站点距离。
- 一键导航：站点卡片和详情页可打开路线弹窗，展示起点/终点、坐标、驾车和步行预计时间。
- 地图选站：用户端地图标记由站点数据动态生成，新增电站后会自动出现在地图中。
- 密码注册：登录页支持免密登录和手机号+密码注册，注册模式包含验证码模拟校验。
- 手动开充：订单页支持扫码模拟和手动输入电桩编号，并选择充满、按时长、按价格、按度数。
- 多支付方式：结算弹窗展示电量、单价、金额、时长、会员折扣，并支持余额、微信、支付宝模拟支付。
- 用户级别：根据累计消费自动计算普通/银卡/金卡/钻石，并在结算时应用折扣。
- 预约超时：预约订单会按演示节奏递减剩余时间，超时后自动释放电桩。
- 用户评价：已完成订单可提交评分和评价内容，提交后会同步到电站详情的 7 日评价列表。
- 信息维护：我的页面支持昵称、头像色块和钱包余额修改，均会同步保存。
- 重置演示：顶部按钮可清空本地模拟数据并恢复初始状态。
